What Do SID (GB922), ODA (IG1228), BSS/OSS, CFS/RFS & 5G UPF Mean in Plain English?

Customer-Ready Demo Cheat Sheet
SID (GB922) 📘 Universal Data Dictionary
Shared Information & Data Model (TM Forum Standard GB922)

Plain-English Meaning: The telecom industry's universal "Common Business & Technical Data Dictionary." It defines standard JSON formats for Products, Services, and Cloud Resources so commercial sales apps and cloud engineering tools speak the exact same language without custom code.

ODA (IG1228) & Canvas 🧩 Plug-and-Play Blueprint
Open Digital Architecture (TM Forum Blueprint IG1228)

Plain-English Meaning: The modern "App Store / Lego-Block Blueprint" for telecom software. Instead of rigid legacy systems, software capabilities (TMFC001–TMFC011) run as plug-and-play microservices on an ODA Canvas (Shared Kubernetes Operating Platform).

BSS vs. OSS 🏢 Front-Office vs. Factory
Business Support Systems vs. Operations Support Systems

Plain-English Meaning: BSS (Front-Office Sales) manages customer product menus, pricing, orders, and billing; OSS (Back-Office Engineering Factory) provisions the actual 5G network slices, cloud routers, and infrastructure.

CFS vs. RFS (TMF633) 🎯 What You Buy vs. How It's Built
Customer-Facing Service vs. Resource-Facing Service

Plain-English Meaning: CFS describes what the customer experiences (e.g., "10 Gbps Ultra-Low Latency 5G Slice"); RFS describes the technical recipe engineering builds under the hood (VPCs, subnets, firewalls, 5G UPF containers).

5G UPF & SGi / N3 / N4 📡 5G High-Speed Data Router
User Plane Function & 3GPP Standard 5G Network Links

Plain-English Meaning: 5G UPF is the high-speed packet engine that routes customer 5G data. It uses three dedicated network highways: N3 (connects 5G cell towers to UPF via GTP-U), N4 (carries control signals via PFCP), and SGi/N6 (connects out to the internet/enterprise cloud).

GKE • eBPF • DPDK • IaC ☁️ Cloud Speed & Security
Google Cloud & Telco Hardware Acceleration Terms

Plain-English Meaning: GKE runs cloud containers; Cilium eBPF enforces strict security walls between tenants; DPDK / SR-IOV / NUMA accelerate network packets at hardware speed (<2ms delay); Terraform IaC builds cloud networks automatically from code.

RULE-LATENCY-01
Input: latency_tier = "Ultra-Low"

Sub-2ms 5G user-plane latency SLA requires hardware NUMA pinning (Dedicated CPU-Memory Alignment), DPDK (High-Speed Kernel-Bypass Packet Processing), and SR-IOV/gVNIC (Direct Hardware Network Acceleration).

machine_type = "c3-standard-8"
cpu_count = 8 | ram_gb = 32
numa_nodes = 2
dpdk_enabled = true
sriov_vf_count = 4
RULE-THROUGHPUT-02
Input: throughput_tier = "10Gbps"

10Gbps sustained GTP-U throughput requires Google Cloud Tier-1 high-bandwidth networking and dedicated 3GPP N3/SGi subnets.

nic_bandwidth_gbps = 10
tier_1_networking = true
sgi_cidr = "10.210.1.0/24"
n3_cidr = "10.210.2.0/24"
n4_cidr = "10.210.3.0/24"
RULE-HA-03
Input: redundancy = "active-standby"

99.999% availability SLA requires dual UPF worker replicas anti-affinitized across two GCP availability zones.

worker_node_count = 2
ha_mode = "active-standby"
zones = "us-central1-a,us-central1-b"
k8s_replicas = 2 (2/2 Ready)
